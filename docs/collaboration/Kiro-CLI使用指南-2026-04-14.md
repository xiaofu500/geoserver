## 概述

Kiro CLI 是一个终端 AI 开发助手，将 AI 辅助开发能力带入命令行环境。无需打开 IDE，即可在终端中完成代码编写、审查、修改和工作流自动化。

**核心能力：**
- 交互式对话：在终端中与 Kiro 进行自然语言对话
- 自定义 Agent：创建和部署专属工作流 Agent
- MCP 集成：通过 Model Context Protocol 连接外部工具和数据源
- 智能 Hooks：自动化工作流的前后置钩子
- Agent Steering：用最佳实践和偏好引导 Agent 行为
- 无头模式：在 CI/CD 流水线中非交互式运行

## 安装

### Windows（PowerShell）

```powershell
irm 'https://cli.kiro.dev/install.ps1' | iex
```

### macOS / Linux

```bash
curl -fsSL https://cli.kiro.dev/install.sh | bash
```

### 快速启动

```bash
cd my-project
kiro-cli
```

## 认证命令

```bash
# 登录（本地自动打开浏览器）
kiro-cli login

# SSH 远程环境登录（设备码流程）
kiro-cli login --use-device-flow

# 社交账号登录
kiro-cli login --social google
kiro-cli login --social github

# Identity Center 企业登录
kiro-cli login --license pro --identity-provider https://my-org.awsapps.com/start --region us-east-1

# 退出登录
kiro-cli logout

# 查看当前登录用户
kiro-cli whoami
kiro-cli whoami --format json
```

## 对话命令（chat）

```bash
# 启动交互式对话
kiro-cli
kiro-cli chat

# 直接提问（非交互）
kiro-cli chat "如何列出所有文件？"

# 非交互模式（适合脚本/CI/CD）
kiro-cli chat --no-interactive --trust-all-tools "显示当前目录"

# 恢复上次对话
kiro-cli chat --resume

# 选择历史会话恢复
kiro-cli chat --resume-picker

# 恢复指定会话
kiro-cli chat --resume-id abc123-def456

# 列出所有历史会话
kiro-cli chat --list-sessions

# 使用指定 Agent
kiro-cli chat --agent my-agent "帮我审查代码"

# 列出可用模型
kiro-cli chat --list-models
kiro-cli chat --list-models --format json
```

## 自然语言转 Shell 命令（translate）

```bash
# 将自然语言描述转换为可执行命令
kiro-cli translate "列出当前目录所有文件"
kiro-cli translate "找出最近一周修改的 Python 文件"
kiro-cli translate "压缩所有超过 30 天的日志文件"

# 生成多个候选命令（最多 5 个）
kiro-cli translate -n 3 "在文件中搜索文本"
```

## Agent 管理

```bash
# 列出所有 Agent
kiro-cli agent list

# 创建 Agent
kiro-cli agent create my-agent

# 编辑 Agent
kiro-cli agent edit my-agent
kiro-cli agent edit          # 编辑当前 Agent

# 设置默认 Agent
kiro-cli agent set-default my-agent

# 验证 Agent 配置
kiro-cli agent validate ./my-agent.json
```

Agent 存储位置：
- 全局：`~/.kiro/agents/`
- 工作区：`.kiro/agents/`

## MCP 服务器管理

```bash
# 列出所有 MCP 服务器
kiro-cli mcp list
kiro-cli mcp list workspace
kiro-cli mcp list global

# 添加 MCP 服务器
kiro-cli mcp add --name my-server --command "node server.js" --scope workspace

# 删除 MCP 服务器
kiro-cli mcp remove --name my-server --scope workspace

# 查看服务器状态
kiro-cli mcp status --name my-server

# 从配置文件导入
kiro-cli mcp import --file config.json workspace
```

## Kiro Command Router（统一入口，v1.26.0+）

解决 `kiro` 命令默认启动 IDE 的问题，安装后可统一控制：

```bash
# 安装路由器
kiro-cli integrations install kiro-command-router

# 设置默认启动 CLI
kiro set-default cli

# 设置默认启动 IDE
kiro set-default ide
```

安装后：
- `kiro` → 启动默认（CLI 或 IDE）
- `kiro-cli` → 始终启动 CLI
- `kiro ide` → 始终启动 IDE

## 交互模式斜杠命令（Slash Commands）

进入 `kiro-cli` 交互模式后，输入 `/` 开头的命令：

### 对话管理

| 命令 | 说明 |
|------|------|
| `/chat new` | 开启新对话 |
| `/chat new <提示词>` | 开启新对话并附带初始提示 |
| `/chat resume` | 选择历史对话恢复 |
| `/chat save <路径>` | 保存当前对话到文件 |
| `/chat load <路径>` | 从文件加载对话 |
| `/compact` | 压缩对话历史（节省 token，适合长对话） |
| `/clear` | 清空当前对话显示 |

### 上下文管理

| 命令 | 说明 |
|------|------|
| `/context show` | 查看当前上下文配置和匹配文件 |
| `/context add src/**/*.ts` | 添加上下文文件（支持 glob） |
| `/context remove src/app.js` | 移除上下文规则 |
| `/context clear` | 清除所有上下文规则 |

### Agent 与模型

| 命令 | 说明 |
|------|------|
| `/model` | 交互式选择 AI 模型 |
| `/model claude-opus-4.6` | 直接指定模型 |
| `/model set-current-as-default` | 将当前模型设为默认 |
| `/agent list` | 列出所有 Agent |
| `/agent create my-agent` | 创建新 Agent |
| `/agent swap code-reviewer` | 运行时切换 Agent |
| `/plan` | 切换到规划 Agent |

### 工具与权限

| 命令 | 说明 |
|------|------|
| `/tools` | 查看所有工具和权限状态 |
| `/tools trust write` | 信任某类工具（不再每次确认） |
| `/tools untrust write` | 取消信任 |
| `/tools trust-all` | 信任所有工具 |
| `/tools reset` | 重置所有权限到默认 |

### 工作区快照（Checkpoint）

> 需先启用：`kiro-cli settings chat.enableCheckpoint true`

| 命令 | 说明 |
|------|------|
| `/checkpoint init` | 创建工作区快照 |
| `/checkpoint list` | 列出所有快照 |
| `/checkpoint restore` | 交互式恢复快照 |
| `/checkpoint restore 2 --hard` | 精确恢复到指定快照 |
| `/checkpoint diff 1 2` | 对比两个快照差异 |

### 知识库管理

> 需先启用：`kiro-cli settings chat.enableKnowledge true`

| 命令 | 说明 |
|------|------|
| `/knowledge add --name docs --path ./docs` | 添加知识库 |
| `/knowledge search "认证流程"` | 语义搜索 |
| `/knowledge show` | 查看所有知识库条目 |
| `/knowledge remove ./docs` | 删除条目 |

### 其他实用命令

| 命令 | 说明 |
|------|------|
| `/help` | 查看帮助 |
| `/mcp` | 查看 MCP 服务器状态 |
| `/paste` | 粘贴剪贴板图片 |
| `/copy` | 复制最后一条回复到剪贴板 |
| `/editor` | 打开编辑器撰写多行提示 |
| `/transcript` | 在分页器中查看完整对话记录 |
| `/usage` | 查看账单和用量 |
| `/hooks` | 查看当前会话的 Hooks |
| `/prompts list` | 列出可用提示模板 |
| `/logdump` | 打包日志文件（用于问题排查） |
| `/quit` | 退出（别名：`/exit`、`/q`） |

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+R` | 反向搜索历史命令 |

| `Ctrl+C` | 取消当前输入 / 退出会话 |

## 日志与调试

```bash
# 设置日志级别（error/warn/info/debug/trace）
export KIRO_LOG_LEVEL=debug
kiro-cli chat

# 禁用彩色日志输出（适合 CI/CD，v1.26.0+）
export KIRO_LOG_NO_COLOR=1
kiro-cli chat
```

日志文件位置：
- macOS：`$TMPDIR/kiro-log/`
- Linux：`$XDG_RUNTIME_DIR` 或 `/tmp/kiro-log/`

> ⚠️ 日志可能包含文件路径、代码片段等敏感信息，分享前请检查内容。

## 会话管理

Kiro CLI 自动保存每次对话，支持跨会话恢复：

```bash
# 命令行恢复
kiro-cli chat --resume
kiro-cli chat --resume-picker
kiro-cli chat --resume-id <SESSION_ID>
kiro-cli chat --list-sessions
kiro-cli chat --delete-session <SESSION_ID>
```

会话存储规则：
- 按目录隔离，每个项目有独立的会话列表
- 最近更新的会话排在最前面
- 会话 ID 为 UUID 格式
