# 代码提交规范

本项目采用 **Conventional Commits** 规范，通过 `commitlint` + `husky` 强制校验。

---

## 提交格式

```
<type>(<scope>): <subject>

[body]

[footer]
```

- `type`：必填，提交类型
- `scope`：可选，影响范围
- `subject`：必填，简短描述（不超过 100 字符，不以句号结尾）
- `body`：可选，详细说明
- `footer`：可选，关联 Issue 或破坏性变更说明

---

## type 类型

| type       | 说明                         | 示例                                      |
| ---------- | ---------------------------- | ----------------------------------------- |
| `feat`     | 新功能                       | `feat(fire): 添加火焰体积渲染效果`        |
| `fix`      | Bug 修复                     | `fix(ca): 修复蔓延概率计算错误`           |
| `docs`     | 文档变更                     | `docs(readme): 更新项目说明`              |
| `style`    | 代码格式（不影响逻辑）       | `style: 统一缩进格式`                     |
| `refactor` | 重构（非新功能/非 Bug 修复） | `refactor(renderer): 重构渲染管线`        |
| `perf`     | 性能优化                     | `perf(ca): 优化格子遍历性能`              |
| `test`     | 测试相关                     | `test: 添加 CA 蔓延单元测试`              |
| `build`    | 构建系统或外部依赖变更       | `build: 升级 Cesium 到 1.123.0`           |
| `ci`       | CI/CD 配置变更               | `ci: 添加自动部署流程`                    |
| `chore`    | 其他杂项                     | `chore: 备份代码`                         |
| `revert`   | 回退提交                     | `revert: revert feat(fire): 添加体积渲染` |

---

## scope 建议

| scope      | 说明               |
| ---------- | ------------------ |
| `fire`     | 火焰渲染相关       |
| `smoke`    | 烟雾渲染相关       |
| `ca`       | 元胞自动机逻辑     |
| `renderer` | 渲染器相关         |
| `hud`      | HUD 界面相关       |
| `demo`     | 演示页面相关       |
| `docs`     | 文档相关           |
| `deps`     | 依赖相关           |

## 示例

```bash
# 新功能
git commit -m "feat(fire): 添加 WebGL 点精灵火焰粒子系统"

# Bug 修复
git commit -m "fix(ca): 修复白烟阶段格子不蔓延的问题"

# 文档
git commit -m "docs: 新增森林火灾体积渲染方案设计文档"

# 重构
git commit -m "refactor(renderer): 用 BillboardCollection 替换 PostProcessStage 烟雾渲染"

# 性能优化
git commit -m "perf(ca): 使用 LOD 聚合减少渲染格子数量"

# 杂项
git commit -m "chore: 备份 2026-04-15 版本代码"

# 带 body 的提交
git commit -m "feat(smoke): 添加高斯烟羽扩散模型

基于 Gaussian Plume Dispersion 模型实现烟雾扩散：
- σy 随高度增大（横向扩散）
- σz 固定（垂直扩散）
- fBm 噪声叠加不规则边缘"
```

## 校验规则

提交时 `husky` 会自动运行 `commitlint` 校验，不符合规范的提交会被**拒绝**。

常见错误：
```
✖ type may not be empty          # type 不能为空
✖ subject may not be empty       # subject 不能为空
✖ type must be one of [...]      # type 不在允许列表中
✖ header must not be longer...   # header 超过 100 字符
```
